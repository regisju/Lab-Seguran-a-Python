# 🧠 Observações do Laboratório

Este projeto foi desenvolvido para estudo de comportamento de ameaças simuladas.

## Aprendizados
- Como arquivos podem ser alterados em massa
- Como logs ajudam na análise de eventos
- Importância de controle de execução de scripts

## Reflexão
Percebi que mesmo simulações simples ajudam a entender impacto de ataques reais sem risco ao sistema.
